# content 管线脚本

针对「真题听力音频 + 听力原文」批量生产课程内容的命令行工具。
所有脚本幂等可重跑：已完成的步骤自动跳过，中断后重跑自动续接。

## 前置条件

- 后端已运行（`npm run dev` 或启动器），且 `backend/.env` 已配置本地 ASR（whisper.cpp）
- 目标课程挂在某个「学习系列」下（先在后台目录结构中创建）

## 原文对齐导入（推荐：有官方听力原文时）

```bash
node scripts/content/yuanwen-apply.mjs
```

对每门**已发布/草稿**且能在原文目录找到对应 md 的课程：
用官方原文文本 + ASR 时间轴合成字幕（原文文本 100% 准确，无识别错误），
Section/Conversation/Passage/Recording 标题自动转为锚点标签。

- 原文目录：`./原文`（脚本内 `YUANWEN_ROOT` 常量，可改）
- ASR 分段从 `media_asr_jobs` 缓存读取，未识别的课程需先跑 ASR
  （后台课程编辑页点「自动切分」，或用下面的批量脚本）

## 批量 ASR + 发布

```bash
node scripts/content/batch-asr-publish.mjs
```

找出所有「草稿且无字幕」的课程，逐门排队本地 ASR → 断句合并 → 写入字幕 →
直接发布（单机版无校对/二审工作流）。37 门真题实测约 3.5 小时（串行队列）。

## 单门补齐 / 状态修复

需要时参考 `temp/fix-two-courses.mjs`（会话工作脚本，按需改造）或直接用后台「发布/下架」按钮。

## 注意

- 这些脚本面向本地单机部署，直接读写本机数据库；不要对着生产环境跑
- 断句规则（指令头拆分/报头独立成行/词级对齐）与后端/前端共用的锚点提取器保持一致
