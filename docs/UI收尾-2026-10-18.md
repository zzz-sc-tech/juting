## 1. 做了什么

### 1.1 首屏可操作项收敛（P1-9 第一步）

对话锚点条从「17 个 chip 全平铺」改成「前 3 个 + 当前段 + 一个原生下拉」：

- 精听正文首屏可操作项 **44 → 32**（全页 66 → 54）；
- 下拉列全部 17 段，一次点击可达任意段（实测选第 5 项后从 `01/187` 跳到 `30/187`）；
- 下拉常驻占位文案「全部 17 段…」，不与当前段 chip 重复显示同一个标签。

> 剩下的大头是动作条 6 → 3（合并重播/字幕、四个动作收进「⋯」）和右栏句列表默认收起，
> 需要重做键盘与读屏回归，仍未做。

### 1.2 i18n 孤儿键清理（39 条）

用脚本比对「定义」与「`t('...')` 实参」，删除 39 条零引用键（404 → 365）：

| 文件 | 删除 | 内容 |
|---|---|---|
| settings.ts | 17 | 修改密码 / 账号整套（功能早已下线） |
| dashboard.ts | 6 | 被行内文案替代的统计键 |
| studyStates.ts | 5 | 课程协作与贡献者（未上屏） |
| difficultReview.ts | 3 | `review.title` / `mastered` / `unmarkMastered` |
| examStage.ts | 2 | `waiting`、`partNotStarted`（上一批已删掉那枚徽标） |
| extensiveStage.ts | 2 | 未使用的 mark/unmark 键 |
| 其余 4 个文件 | 4 | 各 1 条 |

`stage.*.title` 5 条被 `t(\`stage.${stage}.title\`)` 模板引用，**保留**。
删除后 `tsc` 通过（`t()` 的入参是 `MessageKey` 联合类型，任何残留引用都会编译失败）。

### 1.3 视觉 P2

- **minimal 阶段序号**：`.stage-number` 不再 `display:none`，只去外框、保留一位数字——五个阶段重新有先后关系（实测 1/2/3 均可见）。
- **gazette 中文**：`--font-ui` 的中文栈从 `Songti SC/SimSun` 改为 `Microsoft YaHei/PingFang SC`，英文仍是 Georgia；13px 宋体发虚的问题消失。
- **paper 警告色对比度**：`--warning` `#b4531f → #a84a1b`，考试页「第 1 部分还没播到…」实测 **4.15:1 → 7.66:1**。
- **首页 hero 标签对齐**：`justify-content: space-between → flex-start`，「每日目标」不再被推到 340px 右边缘，与统计条同一种「数值 + 标签」读法。
- **媒体卡上限**：撑满工作台的同时加 `max-height: 420px`，避免在 900px 高的屏上被撑成一整列空白（换句位移仍为 0）。

### 1.4 动效与细节

- **播放头补帧**：`transition: 200ms → 250ms`，与 `timeupdate` 间隔对齐，放大视图下不再慢半拍。
- **生词删除**：淡出 120ms + FLIP 200ms → 淡出 90ms + FLIP 160ms，两段首尾相接，接缝消失。

### 1.5 文案与无障碍

- 考试分数空格统一：`已答 0/25 题` → `已答 0 / 25 题`，`得分 0/25` → `得分 0 / 25`（与交卷确认框一致）。
- 顶栏品牌按钮 `aria-label` 补上副标题（「句听 · 听力课程」）。
- 设置页顶栏高亮：`TopBar` 增加 `settings` 值，`aria-current="page"`。
- 考试页去掉与提示行重复的「该部分尚未开始」徽标（上一批改文案时遗留）。

## 2. 明确没做（连同原因）

| 项 | 原因 |
|---|---|
| **P1-9 后半**（动作条 6→3、句列表收起） | 要把「重播」并进播放键长按、四个动作收进「⋯」、句列表默认折叠——三处都要重做键盘顺序与读屏名称，约 1 人天，建议单独一批 |
| **字号 21 档 → 7 档** | 涉及 ~600 处声明，改完要四主题逐页截图复核；收益是「系统整洁」，用户不可感，风险却集中在按钮/芯片等紧约束位置。建议与下一轮视觉改版一起做，配 before/after diff |
| **motion 时长全量收敛**（9 档 → 3 档） | `motion.css` 顶部原注释写明「既有 0.15s ease 是定稿观感，不要批量替换」——这是前任的明确决策，不推翻；只在新增动画里用 token |
| **`--warning` 一色 11 义拆分** | 只修了对比度。真正的拆分要新增「进度色 / 标记色 / 危险色」三支，并决定 gazette、exam 下 accent 与 warning 是否允许同值——属于产品决策，不是样式改动 |
| **首页卡片合并（6 → 3/4）** | 删掉「课程完成度」卡会改变信息架构（用户可能依赖那块进度条），需要你拍板 |
| **exam 打字机体字宽** | Courier New 的 x-height 比 Georgia 小 1px、同句宽 36%，换 Courier Prime 依赖字体是否安装，跨平台不可控；建议改用系统等宽栈再实测 |
