# 真机验收清单（手机浏览器）

> 服务地址：`http://10.70.125.29:8102`（本机 WLAN 网卡，仅同一 Wi-Fi 下可访问）
> 起服务：`cd web-app && npx vite preview --host 0.0.0.0 --port 8102`
> 说明：8101 仍是本机预览；8102 是专门为手机开的局域网实例，`/api` 仍由该进程代理到 8100。

## 打不开时先排查

1. 手机与电脑是否在**同一个 Wi-Fi**（电脑是 `10.70.125.29`，手机应也是 `10.70.125.x`）。
2. Windows 防火墙是否拦了 node 的入站连接——第一次起服务时若弹出提示，要允许「专用网络」。
3. 地址栏补全：`http://10.70.125.29:8102`（**http**，不是 https；端口 8102）。

## 一、横屏学习页（重点 1）

竖屏打开任意课程 → 横过来。

- [ ] 顶栏下方左侧出现**章节窄轨**（不是横跨整屏的目录条），正文从左侧 196px 之后开始
- [ ] 首屏能看到**第一句歌词**或**第一道题的题干**（不是只看到标题和阶段按钮）
- [ ] 章节标题过长时是「…」截断，不是一字一行
- [ ] 阶段导航是**一行横向滑动**，右缘有渐隐，能滑到「模拟实战」

## 二、考试页吸顶题号导航（重点 2）

进入「模拟实战」→ 往下滚。

- [ ] 题号导航是**一行**（不是 4–5 行的方块阵），右缘渐隐提示还有更多
- [ ] 往下滚时题号导航**吸在顶部**，不遮挡题干第一行
- [ ] 点题号能跳到对应题目，跳过去之后当前题号有高亮
- [ ] 题卡与底部「交卷」按钮都不被系统栏遮住

## 三、生词弹层输入（重点 3）

逐句学习 → 点句中任意一个词 → 弹层 → 点输入框。

- [ ] 键盘弹出后，**页面没有自动放大**（字号 ≥16px 的效果）
- [ ] 输入框与「收藏」按钮**没有被键盘遮住**
- [ ] 中文输入法上屏正常，候选栏不遮挡弹层
- [ ] 弹层宽度不超出屏幕右缘

## 四、通用（顺手看一眼）

- [ ] 双击播放键/题号**不会**把整页放大
- [ ] 点按钮**没有蓝色方块**闪一下（tap-highlight 已关）
- [ ] iPhone：底部 Home 指示条不压住「标记难点」那一行动作按钮
- [ ] iPhone Safari：地址栏收起/展开时，正文不跳、不闪
- [ ] 四个主题各切一次（设置 → 界面主题），没有明显错位

## 已知可能出问题的地方（如果发现异常，优先怀疑这些）

| 现象 | 可能原因 |
|---|---|
| 横屏时章节栏宽度不是 196px | 手机浏览器对 `orientation: landscape` 的判断与媒体查询高度阈值（≤480）不符，例如部分安卓浏览器上报的高度含地址栏 |
| 吸顶导航被顶栏盖住 | iOS 的 `position: sticky` 在滚动容器内表现与 Chromium 不同 |
| 底部按钮被 Home 条压住 | `env(safe-area-inset-bottom)` 需要 `viewport-fit=cover` 生效（已加，但仅 PWA/全屏最明显） |
| 键盘弹起后整页上推、弹层错位 | 输入框不在可视区时浏览器会自行滚动，属已知平台行为 |

把发现的每一条按「页面 + 操作 + 现象 + 机型/浏览器」记下来发我，我按现象定位到具体 CSS/组件。
