## 3. 音频：MP3 → opus

### 编码参数（照抄，不要改）

```bash
ffmpeg -hide_banner -loglevel error -y \
  -i "<源文件>.mp3" \
  -map_metadata -1 -vn -ac 1 \
  -c:a libopus -b:a 32k -application voip \
  "temp/cet6-1516/audio/<key>.ogg"
```

- `-ac 1` 单声道，`-b:a 32k` 是现有六级预设的码率
- `-application voip` 对语音最省体积
- `-map_metadata -1` 去元数据，`-vn` 去视频轨

### 旁车文件（必须写）

每个 `.ogg` 旁边要有同名 `.dlt-meta.json`：

```json
{
  "contentType": "audio/ogg"
}
```

漏了这个，播放接口会回退成 `application/octet-stream`。

### 自检

```bash
ffprobe -v error -select_streams a:0 \
  -show_entries format=duration:stream=codec_name,channels \
  -of json "temp/cet6-1516/audio/cet6-2015-06-1.ogg"
```

必须满足：`codec_name=opus`、`channels=1`、`duration>0`。

**体积参考**：现有六级 38 套共 17.1 小时 → opus 合计 217 MB。10 套约 4.5 小时，预期 **55～60 MB**。如果明显超出，检查是不是漏了 `-ac 1`。

## 4. 原文：从「解析」里提取成 md

### 4.1 md 格式（这是硬约束）

```markdown
## Section A

## Conversation 1

W: Hi, David. I haven't seen you in class for almost two weeks.
M: Hi, Sarah. Well, it's a bit of a long story I'm afraid.
W: Oh yeah. There have been so many viruses going around this winter.
Q1. What did Sara think David was doing for the last two weeks?
Q2. What happened to David on his way back from the hospital?

## Conversation 2

M: Welcome to this week's episode of Book Talk.
...

## Section B

## Passage 1

Kate Atkinson was born in York in 1951.
...
Q5. What do we learn about Kate Atkinson?
```

### 4.2 规则逐条

| 规则 | 说明 |
|---|---|
| **分节头** | 必须是 `## Section A` / `## Conversation 1` / `## Passage 1` / `## Recording 1` / `## News Report 1` 这几种形态。编号用阿拉伯数字。**中文分节头（「对话一」「短文理解」）一律不合格** |
| **说话人前缀** | `W:` / `M:` / `Woman:` / `Man:` / `Speaker 1:`。一段话可以含多句，不用一句一行 |
| **题干** | 写成 `Q1. What ...?` —— **用 Q 形式，不要写 `Question 1.`**。解析器只把 `QN.` 识别成题干 |
| **题干编号** | 1～25 必须连续，不能缺号、不能重复 |
| **引号** | **只能用 ASCII 直引号** `'` 和 `"`。禁止弯引号 `’ ‘ " "`——分词器会把 `haven't` 拆成 `haven` + `t`，直接毁掉对齐 |
| **语言** | 只放英文。中文译文、中文解析、中文注释一律剔除 |
| **选项** | 剔除 `A.` `B.` `C.` `D.` 选项行——那是题目选项，不是听力内容 |
| **元数据** | `# 标题`、`> 说明`、`---`、表格、代码块都可以保留，解析器会跳过；也可以直接删掉 |
| **答案/解析** | 全部剔除。只要「听力原文」部分 |

### 4.3 常见坑

1. **「解析」文档里的原文常常和题目、答案混排**。要精确切出「听力原文」那一段，不要整篇复制。
2. **有的解析把题干和正文粘在一起**：`W: Hi David.Q1. What did...` —— 必须拆成两行。
3. **有的解析用中文标点**：`，` `。` `？` —— 原文里的中文标点要换成英文标点（`，`→`,`、`。`→`.`、`？`→`?`）。
4. **有的解析说话人是中文**：`女：` / `男：` —— 换成 `W:` / `M:`。
5. **注意 Section 归属**：六级是 Section A（长对话 2 篇）+ Section B（短文 2 篇）+ Section C（讲座 3 篇），共 25 题。如果某套的解析把 Section 写乱了，按题目编号推：Q1–8 是 Section A，Q9–15 是 Section B，Q16–25 是 Section C。
