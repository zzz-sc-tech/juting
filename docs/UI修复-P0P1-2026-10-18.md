## 2. P0（3/3）

### P0-1 极简主题泛听原文不可读
`styles/themes/minimal.css`：`.extensive-lyric` 由 `--ink-4` 改 `--ink-2`（hover→`--ink`）；`.subtitle-chip:not(.on)` 由 `--ink-4` 改 `--ink-3`。实测 7.73:1。

### P0-2 键盘进不了正文
`components/CourseMap.tsx`：
- 章节列表改 roving tabindex：只有「当前章节」这一行与它的 ⋯ 可 Tab（99 → 3 个 stop），其余行 `tabIndex=-1`；
- `↑ / ↓ / Home / End` 在章节间移动焦点（实测 ↓ 从 1001 到 1002）；
- 任意行 `Shift+F10` / 菜单键唤出 ⋯ 菜单；
- ⋯ 的 `aria-label` 带上章节名（原来 26 个焦点全叫「章节操作」）。

### P0-3 手机横屏首屏零正文
`styles/responsive.css` 新增 `@media (max-height:480px) and (orientation:landscape)`：
章节栏从顶部横条改成 **196px 左侧窄轨**（不用抽屉，章节仍可切）、横幅压到 63px、阶段栏与锚点条强制单行、舞台内边距 22→10、题号导航单行 52px。正文起点 463 → **193**。

## 4. 顺带做的低成本项（原 P2）

- **动效**：阶段入场 200ms→150ms、按阶段序号给方向（前进右来、后退左来）、600ms 内回访不重播（`useLayoutEffect` 打 `.no-enter`）；程序化滚动统一走 `lib/scroll.ts` 的 `smoothOrAuto()`，尊重系统「减少动态效果」。
- **移动手势**：`-webkit-tap-highlight-color: transparent`、可点元素 `touch-action: manipulation`（禁双击缩放）、三个横滚容器 `overscroll-behavior-x: contain` + `scroll-snap` + 右缘渐隐（原来完全没有「右边还有」的暗示）。
- **安全区**：`viewport-fit=cover` + `.app-shell / .settings-page / .dashboard-page` 的 `env(safe-area-inset-bottom)`。
- **触控目标**：歌词插旗用伪元素把热区扩到 44px（视觉仍 24px）；倍速项、章节菜单项、生词弹层按钮、顶栏按钮统一 44px。
- **小屏**：≤360 主题卡改单列（320 下「纸墨书房」原来一字一行）；生词弹层 `width: min(320px, calc(100vw - 28px))`；生词输入框 13→16px（iOS 不再自动缩放）。
- **文案**：难点族收敛为「标记难点 / 移出难点 / 已掌握，移出难点」（删掉「攻克出池」「标为难点」「取消难点」）；「字幕」统一为「原文」；考试页双写提示合并为「第 N 部分还没播到——先往下听，播到这部分才能作答」；空态里的「管理端 / 索引 / 服务已启动」改成用户能执行的下一步；首页「/ 10 句」与「连续学习」单位走 i18n。

## 7. 已知取舍

1. **390 顶栏从 89px 涨到 97px**：触控目标提到 44px 的代价。正文区仍占视口 67.6%，接受。
2. **320 下横幅整块隐藏**：320×640 屏高太紧，而「当前章节」在左侧列表里本来就是高亮行。360 以上保留横幅。
3. **横屏章节栏改窄轨**：比抽屉省一次交互，但 196px 下章节标题只显示一行（省略号），靠 `title` 与读屏名称补全。
4. 仍未做真机验证：iOS Safari 的 `position: sticky`、`env(safe-area-inset-*)` 实际表现，以及软键盘遮挡，都属模拟器结论。
