## 1. 已完成

### 1.1 首页卡片合并

「课程完成度」卡与「继续学习」卡说的是同一件事（都在报某一课的进度），0 门在学时它还只输出一句空话。
改为 **≥2 门在学才出现**：0–1 门时右栏 3 张卡（模拟实战 / 你最常错的题 / 难点复习），多课用户仍能看到并列进度。

实测：零数据 `3` 张卡；3 门在学 `4` 张卡且出现 `.dashboard-courses-card`。

### 1.2 警示色语义拆分

| 语义 | 令牌 | 改了什么 |
|---|---|---|
| 进度 / 进行中 / 已标记 | `--warning` | 保留 |
| 真错误 | `--danger` | 首页「最常错」图标、设置页「更新失败 / 数据导入失败」、复习卡「不认识」 |
| 用户自己的标记 / 模式已开 | `--accent` | 歌词插旗「已标记」、波形 A-B 循环 armed/on |

同时修掉主题层的色彩通道塌陷：gazette 与 exam 原来 `--warning` 与 `--accent` 同值（都是报头红/试卷红），警示与品牌色无法区分。改为赭黄 `#8a5a12`（bg 上 5.2:1），paper 的 warning 也从 `#b4531f` 调到 `#a84a1b`。

实测三主题 `warning ≠ accent` 均成立。

### 1.3 字号 / 字重收敛

| | 修前 | 修后 |
|---|---|---|
| CSS 里的字号声明档位 | 26 档（10 → 40px） | **8 档**（12 / 13 / 14 / 15.5 / 18 / 24 / 28 / 40） |
| 字重档位 | 6 档（含 550 / 650） | **4 档**（400 / 500 / 600 / 700） |
| 实际渲染档位（5 个页面统计） | 21 档 | **5 档**（12 / 13 / 14 / 24 / 28） |

映射规则：`10–12 → 12`、`12.5–13.5 → 13`、`14–15 → 14`、`15.5` 保留（英文正文）、`16–19 → 18`、`20–24 → 24`、`27–30 → 28`、`34/40 → 40`；`550 → 500`、`650 → 600`。

另外补了三处「没显式设字号就落到浏览器默认值」的漏网：`body` 基准字号设 14px（原来是 16px）、`.settings-back` 与 `.rate-trigger` 显式设字号（原来落到 UA 给 button 的 13.333px）、`.dashboard-course-list button` 补 `font: inherit`。

溢出复核：390 与 1440 各 7 个页面，`scrollWidth == clientWidth`，无文字被裁。

### 1.4 生词本本地筛选

搜索页一直宣称「搜句子、生词与课程标题」，但生词本自己没有搜索框——想找一个词只能滚动。

- 生词本页新增筛选框（词形 / 中文释义，本地过滤，不请求接口）；
- 无匹配时给「没有匹配「xxx」的生词」提示；
- 搜索页的生词结果跳转改为 `/vocabulary?q=词`，进页即带筛选（实测 `q=campus` → 1 行）。

## 2. 评估后不做：P1-9 后半（动作条 6→3）

逐个核对后确认**没有可合并项**，再压只能靠隐藏功能：

| 控件 | 为什么不能合并 |
|---|---|
| 播放本句 / 重播 | 暂停态下两者行为相同，但**播放中**只有「重播」能从句子开头重放（精听的核心动作） |
| 去波形循环 | 不是普通跳阶段：它把本句的 A-B 区间一起带进波形并直接进循环态，阶段栏做不到 |
| 原文 | 唯一揭晓入口，与「翻译 / 听写」同属显示开关，但移进 chips 行不减少可操作项计数 |
| 标记难点 / +生词 / 我已掌握 | 学习回路的三次输出，收进「⋯」会让每句话的操作多一次点击 |

句列表也已经是**按分节默认收起、只展开当前段**（`TranscriptPanel` 的 `collapsedIds` 初始值就是全收起），屏幕上那 6 行是当前段本身的内容。

结论：精听首屏 32 个可操作项里，8 行是内容、5 个阶段导航、4 个锚点、9 个动作——都是独立功能。要继续降只能牺牲功能，属产品决策，不属「样式修复」。若你确认要降到 24，可选项是：把「重播」并进播放键长按（牺牲可发现性）、把三个学习动作收进「⋯」（每句多一次点击）。
